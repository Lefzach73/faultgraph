# Public edition and provenance

The public repository is `Lefzach73/faultgraph`; the original
`Lefzach73/faultgraph-lab` remains private and unchanged.

This source-available edition is a curated export of FaultGraph Lab at original
research-archive commit `394e86b98b71a769b7cf3235a395737a0bd90b1e`.
All 40 scientific Python source files are byte-identical to that commit.
The private original retains the complete historical studies and execution record.

This edition contains 228 of the original 284 tests. The 56 omitted cases validate
the private archive's workflow receipts, historical CI accounting and frozen
artifact inventories. Algorithm, property, mutation, paper reproduction,
equivalence, parser, reliability and study-runner tests remain included. The exact
file list and counts are in PUBLIC_EXPORT_MANIFEST.json.

Account billing/API responses, internal task handoffs, workstation-specific logs,
raw CI ZIPs and full private review bundles are excluded. Selected result summaries
and the original v4 report are included unchanged. Original CI URLs in those
historical records may require access to the private archive; this public edition's
CI is a separate engineering check. Historical summary certificates are reported
archive results, not newly rerun certificates for this export.

The public edition has its own integrity manifest. Its verifier checks this export
and the copied source identities; it does not pretend the private archive's full
integrity checks passed on a deliberately smaller tree. No original study artifact
has been overwritten or relabeled by this export.
