# Frozen v4 input subset

These prospective inputs and licensed topology sources are unchanged copies of
the original study. Use `python -m faultgraph.chainstudy study` with `cases.json`
and `manifest.json`, as described in ../../docs/REPRODUCIBILITY.md.

The full private-archive workflow receipts and archive-integrity inventory are
intentionally absent from this public edition. Its separate export verifier checks
source identity and public content. Original hypothesis outcomes are retained in
../../docs/RESULTS.md; a fresh rerun must record its own outcomes and limitations.
